# Проверка симулятора экзамена

[← README](../README.md)

## Ручной запуск

Выполняй симуляцию в интерактивном терминале достаточной высоты:

```bash
cd src
python3 main.py
```

В рабочей среде запуск обработал 20 студентов в терминале размером 42×180 и
показал итоговый отчёт. При высоте окна 24 строки `curses` завершился с ошибкой
отрисовки. Для текущего набора данных запуск занимает около минуты.

Результаты зависят от случайного выбора слов и поведения участников, поэтому
статистика меняется между запусками.

## Автоматические тесты

Автоматические тесты пока отсутствуют. Полезные отдельные проверки:

- чтение корректных файлов и обработка пустых или повреждённых данных;
- выбор вопросов и слов, подсчёт весов ответов;
- учёт настроения, длительности экзамена и перерывов;
- распределение студентов между процессами через общую очередь;
- расчёт текущей и итоговой статистики.

Логику расчётов проверяй отдельно от `curses` и multiprocessing. Для процессов
используй ограниченный интеграционный сценарий.

## Входные данные и рабочий каталог

Программа ищет `examiners.txt`, `students.txt` и `questions.txt` в текущем
каталоге. Запускай её из `src/`, чтобы пути совпадали с расположением файлов.

Возможное улучшение надёжности: передавать исключения из worker-процессов
родительскому процессу в виде типизированных сообщений.
