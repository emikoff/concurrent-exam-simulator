# Симулятор экзамена — Python Bootcamp T02, задание 1

Терминальная симуляция экзамена: студенты стоят в общей очереди, а каждый
экзаменатор принимает их в отдельном процессе. Во время работы программа
обновляет таблицы через `curses`, а после завершения показывает статистику
студентов, экзаменаторов и вопросов.

## Что моделируется

- параллельная работа экзаменаторов и общая очередь студентов;
- выбор трёх вопросов и ответы с весами по правилу золотого сечения;
- набор верных слов экзаменатором и случайное решение о продолжении выбора;
- влияние настроения экзаменатора на результат;
- длительность экзамена, обед после 30 секунд работы и пауза 12–18 секунд;
- текущий статус участников и итоговые показатели экзамена.

Результаты зависят от случайных выборов и могут меняться при каждом запуске.
Входные данные находятся рядом с программой в `src/`.

## Требования и запуск

Нужны Python 3.11 или новее и терминал Linux/Unix с поддержкой `curses`.
Для текущего набора данных используй терминал высотой около 42 строк и шириной
не менее 80 столбцов. Внешние Python-пакеты не используются.

Запусти из каталога `src/`, чтобы программа нашла файлы данных:

```bash
cd src
python3 main.py
```

Не перенаправляй вывод программы в файл: `curses` управляет экраном терминала.
Для выхода дождись завершения всех экзаменаторов.

## Входные файлы

Каждый файл содержит по одной записи в строке:

- `examiners.txt` — имя экзаменатора и пол (`М` или `Ж`);
- `students.txt` — имя студента и пол (`М` или `Ж`), порядок строк задаёт очередь;
- `questions.txt` — банк вопросов, каждый вопрос должен содержать слова.

Для подсчёта ответов требуется не менее трёх вопросов. Примеры данных из
школьного задания сохранены в `src/`.

## Структура

```text
src/
├── main.py       запуск интерфейса и симуляции
├── data.py       чтение входных файлов и создание участников
├── models.py     студенты, экзаменаторы, попытки и события
├── exam.py       выбор слов, вопросы и логика одной попытки
├── runner.py     очередь и отдельные процессы экзаменаторов
├── reports.py    текущие и итоговые таблицы
├── examiners.txt
├── students.txt
└── questions.txt
```

## Соответствие заданию

Программа читает три входных файла, запускает отдельный процесс на каждого
экзаменатора, обрабатывает одну общую очередь и обновляет экран во время
экзамена. Финальный отчёт содержит результаты студентов, статистику
экзаменаторов, лучших студентов и экзаменаторов, отчисляемых студентов,
лучшие вопросы и общий результат экзамена.

План финальной подготовки и проверки находится в
[чек-листе](docs/implementation-guide.md).
